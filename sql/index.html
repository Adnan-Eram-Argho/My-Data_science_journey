02

Create Table

Define the table schema with column names, data types, and constraints. Use cursor.execute() to run the DDL statement, then commit to persist.

Creating the employees table

In [3] 
cursor.execute('''
Create Table If Not Exists employees(
    id Integer Primary Key,
    name Text Not Null,
    age Integer,
    department Text
    )
''')

##commit the changes
sqliteConnection.commit()
Key clauses explained

IF NOT EXISTS — prevents an error if the table already exists; the statement becomes a safe no-op.
PRIMARY KEY — guarantees each row has a unique identifier; SQLite auto-increments integer primary keys.
NOT NULL — the column must always have a value; inserting NULL will raise an error.

⚠ Don't forget commit()

Without commit(), changes are not saved to the database file. They only exist in memory and will be lost when the connection closes.

INSERT

Add rows to a table. You can insert one row at a time with execute(), or batch-insert many rows with executemany() and ? placeholders.

Single inserts

In [4] 
cursor.execute('''
Insert into employees (name,age,department) values ('John',25,'IT')
''')
cursor.execute('''
Insert into employees (name,age,department) values ('Jane',30,'HR')
''')
cursor.execute('''
Insert into employees (name,age,department) values ('Mike',35,'Finance')
''')
sqliteConnection.commit()

Better way — executemany with ? placeholders

In [5] 
sales_data = [
    ('2023-01-01', 'Product A', 100, 'North'),
    ('2023-01-02', 'Product B', 200, 'South'),
    ('2023-01-03', 'Product C', 150, 'East'),
    ('2023-01-04', 'Product D', 300, 'West')
]
cursor.executemany('''
Insert into sales (date, product, sales, region) values (?,?,?,?)
''', sales_data)
connection.commit()
⚠ SQL injection risk

Always use ? placeholders — never build SQL with f-strings or string concatenation. Parameterized queries let SQLite handle escaping, which prevents SQL injection attacks.

SELECT & fetchall

Run a query with execute(), then call fetchall() on the cursor to retrieve the result rows as a list of tuples.

Querying all rows

In [6] 
##query any data from sqlite3
cursor.execute('''
Select * from employees
''')

rows = cursor.fetchall()

## print the queried data
for row in rows:
    print(row)
Out[6] 
(1, 'John', 25, 'IT')
(2, 'Jane', 30, 'HR')
(3, 'Mike', 35, 'Finance')
execute() vs fetchall()

execute() only runs the query and returns the cursor object (<sqlite3.Cursor at 0x...>); you need fetchall() to actually retrieve the rows. Use fetchone() if you only need the first matching row.

UPDATE & DELETE

Modify existing rows with UPDATE ... SET ... WHERE, or remove rows with DELETE FROM ... WHERE. Always include a WHERE clause unless you genuinely want to affect every row.

Updating a row

In [7] 
## update the data
cursor.execute('''
Update employees set age = 28 where name = 'John'
''')
sqliteConnection.commit()

Deleting a row

In [8] 
## delete the data
cursor.execute('''
Delete from employees where name = 'Jane'
''')
sqliteConnection.commit()

Verify changes

In [9] 
cursor.execute('''
Select * from employees
''')
rows = cursor.fetchall()
for row in rows:
    print(row)
Out[9] 
(1, 'John', 28, 'IT')
(3, 'Mike', 35, 'Finance')
⚠ UPDATE / DELETE without WHERE

UPDATE without a WHERE clause modifies every row in the table. DELETE without WHERE removes all rows. Always double-check your filter condition before running these statements.

DROP TABLE & Close Connection

DROP TABLE permanently removes a table and all its data. connection.close() releases the database file lock.

Dropping a table

In [10] 
## delete the whole table
cursor.execute('''
DROP TABLE employees
''')

Closing the connection

In [11] 
## close the connection properly
connection.close()
Permanent deletion

DROP TABLE removes the table and all its data permanently — there is no undo. Always close the connection at the end of your script to release the database file lock and flush any pending changes.

import sqlite3

##  working with sales data
connection = sqlite3.connect('sales_data.db')
cursor = connection.cursor()

##create a table for sales data
cursor.execute('''
CREATE TABLE IF NOT EXISTS sales(
    id INTEGER PRIMARY KEY,
    date  TEXT NOT NULL,
    product TEXT NOT NULL,
    sales INTEGER,
    region TEXT)
''')
connection.commit()
