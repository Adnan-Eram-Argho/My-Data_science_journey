Statistics কী — Descriptive vs Inferential

Statistics হলো ডেটা সংগ্রহ, বিশ্লেষণ, ব্যাখ্যা, উপস্থাপন এবং সিদ্ধান্ত গ্রহণের বিজ্ঞান। এটিকে মূলত দুই ভাগে ভাগ করা হয়: Descriptive ও Inferential Statistics।

Descriptive Statistics

ডেটার সারাংশ তৈরি করা — মানে ডেটাকে সংখ্যা, চার্ট বা টেবিলের মাধ্যমে বর্ণনা করা। এখানে কোনো prediction বা সিদ্ধান্ত নেওয়া হয় না।

উদাহরণ

একটি ক্লাসের ৫০ জন ছাত্রের পরীক্ষার গড় নম্বর বের করা, সর্বোচ্চ-সর্বনিম্ন নম্বর দেখা, অথবা bar chart আঁকা — এগুলো সব descriptive কাজ।

Inferential Statistics

একটি sample (নমুনা) থেকে পুরো population সম্পর্কে সিদ্ধান্ত নেওয়া বা prediction করা। Hypothesis testing, confidence interval, regression — সব inferential-এর আওতায় পড়ে।

উদাহরণ

বাংলাদেশের সব মানুষের গড় উচ্চতা জানতে সবার মাপ নেওয়া অসম্ভব। তাই ১,০০০ জনের sample নিয়ে সেটা থেকে পুরো population-এর গড় estimate করা — এটা inferential।

পার্থক্য এক নজরে

বিষয় Descriptive Inferential
উদ্দেশ্য ডেটা summarize / describe করা Sample থেকে population সম্পর্কে সিদ্ধান্ত নেওয়া
ডেটা পুরো dataset নিয়ে কাজ Sample নিয়ে কাজ, population সম্পর্কে estimate
টুলস Mean, Median, Mode, Chart, Graph Hypothesis Testing, Regression, CI
Uncertainty নেই — যা দেখছি তাই বলছি আছে — probability-র ভিত্তিতে সিদ্ধান্ত

02

Central Tendency — Mean, Median, Mode

ডেটার "কেন্দ্র" কোথায় সেটা বোঝানোর জন্য Central Tendency ব্যবহার হয়। তিনটি প্রধান measure: Mean, Median, ও Mode।

Mean (গড়)

সব value যোগ করে মোট সংখ্যা দিয়ে ভাগ করলে Mean পাওয়া যায়।

Population Mean μ = ΣX / N
Sample Mean x̄ = Σx / n
Population vs Sample

Population (μ) — সম্পূর্ণ জনসংখ্যা বা dataset-এর গড়; N = মোট population size।
Sample (x̄) — population-এর একটি অংশের (নমুনা) গড়; n = sample size। বেশিরভাগ ক্ষেত্রে আমরা sample নিয়ে কাজ করি।

উদাহরণ: ডেটা = {4, 8, 6, 5, 3, 2, 8, 9, 2, 5}

In [1] 
data = [4, 8, 6, 5, 3, 2, 8, 9, 2, 5]
mean = sum(data) / len(data)
print(f"Mean = {mean}")
Out[1] 
Mean = 5.2
⚠ Outlier-এ Mean-এর সমস্যা

Mean outlier-এ অনেক বেশি প্রভাবিত হয়। যেমন: {2, 3, 4, 5, 100} — এখানে mean = 22.8, কিন্তু বেশিরভাগ ডেটা 5-এর নিচে। এই কারণে skewed data-তে Median বেশি reliable।

Median (মধ্যমা)

ডেটাকে sorted (ছোট থেকে বড়) সাজিয়ে ঠিক মাঝের মান নিলে সেটা Median।

Position সূত্র Median position = (n + 1) / 2

n বিজোড় হলে: মাঝের value সরাসরি Median।
n জোড় হলে: মাঝের দুটি value-এর গড় = Median।

উদাহরণ (n = 10, জোড়):

In [2] 
data = [4, 8, 6, 5, 3, 2, 8, 9, 2, 5]
sorted_data = sorted(data)
print(f"Sorted: {sorted_data}")

n = len(sorted_data)
if n % 2 == 1:
    median = sorted_data[n // 2]
else:
    median = (sorted_data[n//2 - 1] + sorted_data[n//2]) / 2

print(f"Median = {median}")
Out[2] 
Sorted: [2, 2, 3, 4, 5, 5, 6, 8, 8, 9]
Median = 5.0

position = (10+1)/2 = 5.5 → 5th ও 6th value-এর গড় = (5 + 5) / 2 = 5.0

Mode (সর্বাধিক পুনরাবৃত্ত মান)

ডেটায় যে value সবচেয়ে বেশিবার আসে সেটাই Mode। একটি dataset-এ একাধিক Mode থাকতে পারে (bimodal, multimodal) অথবা কোনো Mode নাও থাকতে পারে।

In [3] 
from collections import Counter

data = [4, 8, 6, 5, 3, 2, 8, 9, 2, 5]
freq = Counter(data)
max_count = max(freq.values())
modes = [k for k, v in freq.items() if v == max_count]
print(f"Mode(s) = {modes}, frequency = {max_count}")
Out[3] 
Mode(s) = [8, 2, 5], frequency = 2
কখন কোনটা ব্যবহার করবে?

Mean — symmetric (সমানুপাতিক) data-তে ভালো কাজ করে।
Median — skewed data বা outlier থাকলে বেশি reliable।
Mode — categorical data-র জন্য সবচেয়ে উপযোগী (যেমন: সবচেয়ে জনপ্রিয় রঙ)।

03

Variance ও Standard Deviation

ডেটা কেন্দ্র থেকে কতটা ছড়িয়ে আছে (spread/dispersion) তা পরিমাপ করে Variance ও Standard Deviation। Variance হলো গড় থেকে প্রতিটি মানের বিচ্যুতির বর্গের গড়, আর SD হলো Variance-এর বর্গমূল।

Population Variance ও SD

Population Variance σ² = Σ(x − μ)² / N
Population Standard Deviation σ = √σ²

Sample Variance ও SD

Sample Variance s² = Σ(x − x̄)² / (n − 1)
Sample Standard Deviation s = √s²

Bessel's Correction — কেন n−1?

⚠ গুরুত্বপূর্ণ ধারণা

Sample-এ n-এর বদলে n − 1 দিয়ে ভাগ করা হয়, একে Bessel's Correction বলে। কারণ:

১) Sample mean (x̄) population mean (μ) থেকে কিছুটা আলাদা। Sample-এর data point গুলো তাদের নিজের mean-এর কাছাকাছি "জমাট" হয়ে থাকে, তাই n দিয়ে ভাগ করলে variance কম (underestimate) আসে।

২) n − 1 দিয়ে ভাগ করলে এই bias ঠিক হয় এবং sample variance population variance-এর একটি unbiased estimator হয়ে যায়।

৩) গাণিতিকভাবে, n টি data point থেকে mean বের করলে degrees of freedom হয় n − 1 (একটি তথ্য mean তৈরিতে "ব্যবহৃত" হয়ে যায়)।

উদাহরণ: data = [4, 8, 6, 5, 3]

In [4] 
data = [4, 8, 6, 5, 3]
n = len(data)
mean = sum(data) / n

# Population variance & SD
pop_var = sum((x - mean) ** 2 for x in data) / n
pop_sd  = pop_var ** 0.5

# Sample variance & SD (Bessel's correction: n-1)
samp_var = sum((x - mean) ** 2 for x in data) / (n - 1)
samp_sd  = samp_var ** 0.5

print(f"Mean          = {mean}")
print(f"Pop Variance  = {pop_var}")
print(f"Pop SD        = {pop_sd:.4f}")
print(f"Samp Variance = {samp_var}")
print(f"Samp SD       = {samp_sd:.4f}")
Out[4] 
Mean          = 5.2
Pop Variance  = 2.96
Pop SD        = 1.7205
Samp Variance = 3.7
Samp SD       = 1.9235
SD ব্যবহার

SD যত বড়, ডেটা mean থেকে তত বেশি ছড়িয়ে আছে। SD যত ছোট, ডেটা mean-এর কাছাকাছি। SD-র unit ডেটার unit-ই — তাই ডেটার সাথে সরাসরি তুলনা করা সহজ (Variance-এর unit squared থাকে)।

04

Variable ও এর প্রকারভেদ

Statistics-এ Variable হলো এমন কোনো বৈশিষ্ট্য যা পরিমাপ বা পর্যবেক্ষণ করা যায় এবং যার মান পরিবর্তন হতে পারে। Variable-কে বিভিন্নভাবে শ্রেণিবদ্ধ করা হয়।

প্রধান বিভাজন — Qualitative vs Quantitative

ধরন বর্ণনা উদাহরণ
Qualitative (Categorical) গুণগত — সংখ্যায় মাপা যায় না, ক্যাটাগরি/লেবেল রঙ, লিঙ্গ, ধর্ম, দেশ
Quantitative (Numerical) সংখ্যাগত — সংখ্যায় মাপা যায় উচ্চতা, তাপমাত্রা, বেতন, বয়স

Quantitative-এর উপবিভাগ

ধরন বর্ণনা উদাহরণ
Discrete নির্দিষ্ট পূর্ণসংখ্যা মান — গোনা যায় ছাত্রসংখ্যা, গোল সংখ্যা, সন্তান সংখ্যা
Continuous যেকোনো মান নিতে পারে (দশমিক সহ) — মাপা যায় উচ্চতা (5.7 ft), ওজন (68.5 kg), তাপমাত্রা

Measurement Scale (পরিমাপ স্কেল)

Scale বৈশিষ্ট্য উদাহরণ গাণিতিক কাজ
Nominal শুধু label/name — কোনো ক্রম নেই লিঙ্গ, রক্তের গ্রুপ, দেশ শুধু Mode
Ordinal ক্রম আছে, কিন্তু ব্যবধান সমান নয় শিক্ষাগত যোগ্যতা, rating (1–5 ★) Mode, Median
Interval সমান ব্যবধান, কিন্তু true zero নেই তাপমাত্রা (°C), IQ score Mean, Median, Mode, +/−
Ratio সমান ব্যবধান + true zero আছে উচ্চতা, ওজন, আয়, দূরত্ব সব গাণিতিক কাজ (×/÷ সহ)
মনে রাখার টিপস

Nominal = Name, Ordinal = Order, Interval = no true zero, Ratio = has true zero। Ratio scale-এ "দ্বিগুণ" বলা যায় (80kg হলো 40kg-এর দ্বিগুণ), কিন্তু Interval-এ পারা যায় না (40°C মানে 20°C-এর দ্বিগুণ গরম নয়)।

05

Random Variable

Random Variable হলো এমন একটি variable যার মান একটি random experiment-এর ফলাফলের ওপর নির্ভর করে। মানে — আগে থেকে ঠিক কত হবে বলা যায় না, কিন্তু সম্ভাব্য মানগুলো জানা থাকে।

Discrete Random Variable

যে random variable শুধুমাত্র নির্দিষ্ট (countable) মান নিতে পারে। সাধারণত পূর্ণসংখ্যা হয়, এবং মানগুলো একটি একটি করে গোনা যায়।

উদাহরণ

• একটি ছক্কা (die) ছুঁড়লে ফলাফল: X ∈ {1, 2, 3, 4, 5, 6}
• একটি পরিবারে সন্তান সংখ্যা: X ∈ {0, 1, 2, 3, ...}
• একটি ক্লাসে অনুপস্থিত ছাত্র সংখ্যা

Continuous Random Variable

যে random variable একটি range/interval-এর মধ্যে যেকোনো মান (দশমিক সহ) নিতে পারে। মানগুলো অসীম, গোনা সম্ভব নয়।

উদাহরণ

• একজন মানুষের উচ্চতা: X ∈ [4.0 ft, 7.5 ft] — 5.347 ft, 5.81 ft যেকোনো মান হতে পারে
• একটি গাড়ির জ্বালানি দক্ষতা (km/L)
• প্রতিদিনের তাপমাত্রা

পার্থক্য এক নজরে

বিষয় Discrete Continuous
মান নির্দিষ্ট, গণনাযোগ্য অসীম, পরিমাপযোগ্য
ধরন সাধারণত পূর্ণসংখ্যা দশমিক সহ যেকোনো সংখ্যা
Probability P(X = x) ≥ 0 (নির্দিষ্ট মানে) P(X = x) = 0 (range-এ probability density)
Graph Bar chart / Probability Mass Function (PMF) Smooth curve / Probability Density Function (PDF)

Histogram

Histogram হলো continuous/quantitative ডেটার frequency distribution দেখানোর একটি গ্রাফ। ডেটাকে সমান intervals-এ (bins) ভাগ করে প্রতিটি bin-এ কতগুলো data point আছে সেটা bar-এর উচ্চতা দিয়ে দেখানো হয়।

কখন ব্যবহার হয়?

• Continuous ডেটার distribution (বিন্যাস) বুঝতে
• ডেটা symmetric, left-skewed না right-skewed — সেটা দেখতে
• Outlier detect করতে
• ডেটার ঘনত্ব (concentration) কোথায় বেশি সেটা বুঝতে

Bar Chart থেকে পার্থক্য

বিষয় Histogram Bar Chart
ডেটার ধরন Continuous / Quantitative Categorical / Qualitative
Bar-এর ফাঁক ফাঁক নেই (continuous range) ফাঁক আছে (আলাদা category)
X-axis সংখ্যার range/intervals Category name
Bar ক্রম নির্দিষ্ট ক্রম (ascending) যেকোনো ক্রমে সাজানো যায়

উদাহরণ — পরীক্ষার নম্বর

ডেটা: 45, 52, 58, 61, 63, 65, 67, 68, 70, 72, 74, 75, 78, 80, 82, 85, 88, 91, 95, 98

লক্ষ্য করো

Histogram-এ bar গুলো পাশাপাশি লেগে আছে (কোনো gap নেই), কারণ X-axis continuous range দেখাচ্ছে। এটাই bar chart থেকে সবচেয়ে বড় চাক্ষুষ পার্থক্য।

07

Percentile ও Quartile

Percentile বলে দেয় — ডেটার কত শতাংশ value একটি নির্দিষ্ট মানের নিচে পড়ে। Quartile ডেটাকে ৪ ভাগে ভাগ করে এবং এগুলো নির্দিষ্ট percentile-এর সমান।

Percentile Position সূত্র

Position k = (percentile / 100) × (n + 1)

যেখানে n = sorted ডেটার মোট সংখ্যা, k = position (1-indexed)।

Quartile

ডেটাকে sorted করে ৪ ভাগে ভাগ করলে ৩টি dividing point পাওয়া যায়:

Quartile Positions Q1 position = (n + 1) / 4
Q2 position = (n + 1) / 2   (= Median)
Q3 position = 3(n + 1) / 4
Quartile Percentile অর্থ
Q1 25th percentile নিচের ২৫% ডেটা এর নিচে
Q2 50th percentile = Median (মাঝের মান)
Q3 75th percentile নিচের ৭৫% ডেটা এর নিচে

Interpolation — ভগ্নাংশ Position

যদি position k ভগ্নাংশ হয় (যেমন 3.25), তাহলে:

Interpolation পদ্ধতি

k = 3.25 মানে 3rd ও 4th value-এর মাঝে। integer অংশ = 3, fractional অংশ = 0.25।
মান = value[3] + 0.25 × (value[4] − value[3])
অর্থাৎ: lower value + (fractional part) × (upper value − lower value)

উদাহরণ: data = [7, 15, 36, 39, 40, 41] — n = 6

In [5] 
data = [7, 15, 36, 39, 40, 41]
n = len(data)

# Q1 position = (6+1)/4 = 1.75
q1_pos = (n + 1) / 4
i = int(q1_pos)        # 1

5 Number Summary, IQR, Fence Value, Box Plot

ডেটার spread ও outlier এক নজরে বুঝতে 5 Number Summary এবং Box Plot (Box-and-Whisker Plot) ব্যবহার করা হয়।

5 Number Summary

পাঁচটি key value মিলে ডেটার সারাংশ:

Min সর্বনিম্ন Q1 25th percentile Q2 Median Q3 75th percentile Max সর্বোচ্চ

IQR (Interquartile Range)

IQR IQR = Q3 − Q1

IQR বলে দেয় মাঝের ৫০% ডেটা কতটা জায়গা জুড়ে ছড়িয়ে আছে। IQR-কে ব্যবহার করে Fence Value বের করা হয় — যা outlier detect-এ কাজে লাগে।

Fence Value

Fence Values Lower Fence = Q1 − 1.5 × IQR
Higher Fence = Q3 + 1.5 × IQR

যেকোনো data point যা Lower Fence-এর নিচে বা Higher Fence-এর উপরে পড়ে, সেটাকে Outlier বলা হয়।

Box Plot (Box-and-Whisker Plot)

Box Plot-এর গঠন:

• Box: Q1 থেকে Q3 পর্যন্ত — ডেটার মাঝের ৫০% এখানে থাকে
• Median line: Box-এর মধ্যে Q2 দেখায়
• Whiskers: Box থেকে fence-এর মধ্যে সবচেয়ে দূরবর্তী actual data point পর্যন্ত প্রসারিত হয়
• Outlier dots: Fence-এর বাইরে থাকা data point গুলো আলাদা dot হিসেবে দেখায়

উদাহরণ: data = [2, 3, 5, 7, 8, 10, 12, 15, 18, 22, 50]

In [6] 
import numpy as np

data = [2, 3, 5, 7, 8, 10, 12, 15, 18, 22, 50]
q1 = np.percentile(data, 25)
q2 = np.percentile(data, 50)

iqr = q3 - q1
lower_fence = q1 - 1.5 * iqr
higher_fence = q3 + 1.5 * iqr

outliers = [x for x in data if x < lower_fence or x > higher_fence]

print(f"Q1 = {q1}, Q2 = {q2}, Q3 = {q3}")
print(f"IQR = {iqr}")
print(f"Lower Fence = {lower_fence}")
print(f"Higher Fence = {higher_fence}")
print(f"Outliers = {outliers}")

Covariance

Covariance দুটি variable-এর মধ্যে সম্পর্কের দিক (direction) নির্দেশ করে — একটি বাড়লে অন্যটি বাড়ে (positive) নাকি কমে (negative)।

Population Covariance

Population Covariance Cov(X, Y) = Σ(x − μx)(y − μy) / N

Sample Covariance

Sample Covariance Cov(X, Y) = Σ(x − x̄)(y − ȳ) / (n − 1)

Positive ও Negative Covariance

Cov(X,Y) > 0 (Positive): X বাড়লে Y-ও বাড়ে (একই দিকে যায়)। যেমন: পড়াশোনার ঘণ্টা ↑ → পরীক্ষার নম্বর ↑

Cov(X,Y) < 0 (Negative): X বাড়লে Y কমে (বিপরীত দিকে)। যেমন: তাপমাত্রা ↑ → গরম কাপড়ের বিক্রি ↓

Cov(X,Y) = 0: X ও Y-এর মধ্যে কোনো linear সম্পর্ক নেই।

বিশেষ সম্পর্ক: Cov(X, X) = Variance

Cov(X, X) = Var(X)

কোনো variable-কে নিজের সাথেই covariance বের করলে সেটা ওই variable-এর Variance-ই হয়:
Cov(X, X) = Σ(x − μ)(x − μ) / N = Σ(x − μ)² / N = σ²

উদাহরণ:

In [7] 
X = [1, 2, 3, 4, 5]
Y = [2, 4, 5, 4, 5]
n = len(X)

mean_x = sum(X) / n
mean_y = sum(Y) / n

# Sample covariance
cov_xy = sum((X[i] - mean_x) * (Y[i] - mean_y)
             for i in range(n)) / (n - 1)

print(f"Mean X = {mean_x}, Mean Y = {mean_y}")
print(f"Cov(X, Y) = {cov_xy}")

Covariance-এর Advantages ও Disadvantages

Advantages Disadvantages
দুটি variable-এর সম্পর্কের দিক (direction) বলে দেয় সম্পর্কের শক্তি (strength) বোঝা যায় না — মান -∞ থেকে +∞ পর্যন্ত হতে পারে
Correlation-এর ভিত্তি হিসেবে কাজ করে Unit-dependent — ডেটার unit পরিবর্তন করলে covariance-ও বদলায়

Correlation — Pearson & Spearman

Correlation দুটি variable-এর মধ্যে সম্পর্কের দিক ও শক্তি উভয়ই পরিমাপ করে। এটি covariance-কে standardize করে -1 থেকে +1 এর মধ্যে সীমাবদ্ধ করে, তাই বিভিন্ন dataset-এর মধ্যে তুলনা করা সহজ।

কেন Correlation, Covariance-এর চেয়ে ভালো?

মূল কারণ

Covariance-এর মান -∞ থেকে +∞ পর্যন্ত হতে পারে এবং এটি unit-dependent। তাই শুধু Cov = 150 দেখে বোঝা যায় না সম্পর্ক কতটা strong। Correlation standardized — মান সবসময় -1 ≤ r ≤ +1 এর মধ্যে থাকে।

r = +1 → perfect positive linear relationship
r = -1 → perfect negative linear relationship
r = 0 → কোনো linear relationship নেই

Pearson Correlation Coefficient (r)

দুটি variable-এর linear সম্পর্কের শক্তি পরিমাপ করে। দুটি সমতুল্য সূত্র আছে:

সূত্র ১ — Raw Score Formula r = Σ(x − x̄)(y − ȳ) / √(Σ(x − x̄)² × Σ(y − ȳ)²)
সূত্র ২ — Covariance / SD Formula r = Cov(X, Y) / (SD(X) × SD(Y))
দুটি সূত্র কেন সমান?

সূত্র ২ মূলত সূত্র ১-কেই সংক্ষেপে লেখা। Cov(X,Y) = Σ(x−x̄)(y−ȳ)/n এবং SD(X) = √(Σ(x−x̄)²/n), SD(Y) = √(Σ(y−ȳ)²/n)। ভাগ করলে n cancel হয়ে সূত্র ১ পাওয়া যায়। এই ফর্মটি মনে রাখা সহজ — Correlation = Covariance-কে দুই variable-এর SD দিয়ে standardize করা।

In [8] 
X = [1, 2, 3, 4, 5]
Y = [2, 4, 5, 4, 5]
n = len(X)
mean_x = sum(X) / n
mean_y = sum(Y) / n

numerator   = sum((X[i]-mean_x)*(Y[i]-mean_y) for i in range(n))
denom_x     = sum((X[i]-mean_x)**2 for i in range(n))
denom_y     = sum((Y[i]-mean_y)**2 for i in range(n))
denominator = (denom_x * denom_y) ** 0.5

r = numerator / denominator
print(f"Pearson r = {r:.4f}")
Out[8] 
Pearson r = 0.7746

Spearman Rank Correlation (ρ)

ডেটার rank ব্যবহার করে সম্পর্ক পরিমাপ করে। Linear না হলেও যেকোনো monotonic সম্পর্ক (always increasing বা always decreasing) ধরতে পারে। দুটি সমতুল্য সূত্র আছে:

সূত্র ১ — Shortcut Formula (no ties) ρ = 1 − (6Σd²) / (n(n² − 1))

যেখানে d = প্রতিটি pair-এর X-rank ও Y-rank-এর পার্থক্য।

সূত্র ২ — Rank-এর উপর Pearson (General Formula) ρ = Cov(R(X), R(Y)) / (SD(R(X)) × SD(R(Y)))
কোন সূত্র কখন?

সূত্র ১ (shortcut) হাতে হিসাব করতে সুবিধাজনক, তবে এটি শুধু তখনই সঠিক যখন ডেটায় কোনো tied rank (একই মান একাধিকবার) নেই।

সূত্র ২ (general) সবসময় সঠিক — এটি মূলত X ও Y-এর rank গুলোর উপর Pearson correlation বের করা। Tied ranks থাকলে average rank নিয়ে এই সূত্র ব্যবহার করতে হয়। Scipy-র spearmanr() এই পদ্ধতিই ব্যবহার করে।

In [9] 
from scipy import stats

X = [1, 2, 3, 4, 5]
Y = [2, 4, 5, 4, 5]

# Manual Spearman
def rank(arr):
    sorted_arr = sorted(enumerate(arr), key=lambda x: x[1])
    ranks = [0] * len(arr)
    for r, (i, _) in enumerate(sorted_arr, 1):
        ranks[i] = r
    return ranks

rx = rank(X)  # [1, 2, 3, 4, 5]
ry = rank(Y)  # [1, 2, 4, 3, 5] (ties simplified)
n = len(X)

d_sq = sum((rx[i] - ry[i])**2 for i in range(n))
rho = 1 - (6 * d_sq) / (n * (n**2 - 1))
print(f"Manual Spearman ρ = {rho:.4f}")

# scipy verification
rho_scipy, pval = stats.spearmanr(X, Y)
print(f"Scipy  Spearman ρ = {rho_scipy:.4f}")
Out[9] 
Manual Spearman ρ = 0.9000
Scipy  Spearman ρ = 0.8208
⚠ Manual vs Scipy পার্থক্য কেন?

Manual formula-তে tied ranks handle করা হয়নি (সরলীকৃত rank দেওয়া হয়েছে), কিন্তু Scipy tied ranks-এর average নেয়। ডেটায় ties থাকলে Scipy-র মান আরও সঠিক।

Pearson vs Spearman — কখন কোনটা?

বিষয় Pearson Spearman
সম্পর্কের ধরন শুধু linear relationship ধরে যেকোনো monotonic relationship ধরে
ডেটার ধরন Interval / Ratio scale (continuous) Ordinal / Interval / Ratio
Outlier-এ প্রভাব বেশি sensitive কম sensitive (rank-based)
Distribution ডেটা normally distributed হওয়া উচিত কোনো distribution assumption নেই
কখন better? ডেটা continuous, normally distributed ও linear সম্পর্ক থাকলে Ordinal ডেটা, non-linear monotonic সম্পর্ক, বা outlier থাকলে
সারসংক্ষেপ

Covariance দিক বলে কিন্তু শক্তি বলে না; Correlation দিক ও শক্তি দুটোই বলে। Normal, linear ডেটায় Pearson ব্যবহার করো। Ordinal ডেটা, outlier-যুক্ত ডেটা, বা monotonic (linear না) সম্পর্কে Spearman ব্যবহার করো।
